# Product-demo production method

Starting principles by Amir Mushich. Adapt their aesthetic defaults to the user's approved style.

1. **Show a real behavior.** Begin with a working artifact and a coherent interaction sequence. Preserve the action, active object, essential UI and cursor context. A concept study must not become a claim of client work.
2. **Choose the proof before writing the hook.** Decide what the viewer can actually see the product do. Keep the headline and caption consistent with that evidence.
3. **Compose for the destination.** Reframe horizontal footage without losing context. Use a full-width inset when cropping would destroy the interaction. Avoid speeding up deliberately timed UI just to shorten the video.
4. **Let the demonstration carry the explanation.** Start with a concise headline and readable product. Add labels only where the viewer needs them. Put technical process details and credits in the caption when that suits the destination.
5. **Keep style personal.** Learn typography, alignment, spacing, framing and motion from the user's evidence. Amir's optional Reel starting layout is one centered headline block, no explanatory microcopy, no divider lines and no periods at headline line endings. It is an overridable default, not a universal identity.
6. **Use the actual assets.** If an opening transition is supplied, record its start frame, blend mode, opacity and SFX gain. Select an actual music segment, listen to it, record offset/gain/fades and balance it separately from SFX. No asset is included just because it was used in Amir's workflow.
7. **Verify the rendered output.** Check legibility, framing, seams, timing, audio peaks and the beginning/end. Preserve source UI labels. Choose a cover that represents the product. A runnable-looking render script is not a rendered preview.
8. **Keep provenance precise.** Separate the code agent, media model/provider and original concept author. Do not invent engagement improvements or time savings.

For stills, select a legible real product state and preserve interface fidelity. Create an image/carousel only when that format has been requested or chosen. Keep the approved master and reproducible recipe locally.
